### boundaries/footnote (source): known

Reason: The footnote body is out-of-flow content. Intended output keeps it as its own unit at its position.

Known limitation: A footnote call is an inline value like any content block, so its body joins the sentence: 'Text before the note. Footnote text here.'. The walker does not match the name footnote, because a user definition can shadow the built-in.

Expected:

```text
Text before the note.

Footnote text here.

Text after the note.
```

Observed:

```text
Text before the note. Footnote text here.

Text after the note.
```

### boundaries/table-cells (source): known

Reason: Each cell is a separate unit.

Known limitation: A table cell is an inline value, so the cells join on one line: 'CellOne CellTwo'. Source mode cannot tell a table from an inline call.

Expected:

```text
CellOne

CellTwo
```

Observed:

```text
CellOne CellTwo
```

### boundaries/nested-block (source): known

Reason: A nested block is a separate paragraph of the outer block.

Known limitation: Trailing content of a call is treated as inline, so the nested block joins the outer block text ('OuterBlock NestedBlock'). Source mode cannot tell a block call from an inline call.

Expected:

```text
OuterBlock

NestedBlock
```

Observed:

```text
OuterBlock NestedBlock
```

## Known limitations

- A footnote call is an inline value like any content block, so its body joins the sentence: 'Text before the note. Footnote text here.'. The walker does not match the name footnote, because a user definition can shadow the built-in.
  - source exact text (boundaries/footnote)
- A line break written as a call, #linebreak(), is a value expression, so the source writes the placeholder between the label and the value.
  - source exact text (compiled-gaps/grid-labels)
- A table cell is an inline value, so the cells join on one line: 'CellOne CellTwo'. Source mode cannot tell a table from an inline call.
  - source exact text (boundaries/table-cells)
- Each content block is set off by a space, so the word 'ab' is split into 'a b'. A split word is preferred to a glued one, because the source does not show the layout.
  - source exact text (content-values/adjacent-trailing)
- Source mode cannot tell a figure from an inline call, so the caption joins the sentence: 'The figure follows Legend text and ends.'
  - source exact text (content-values/figure-in-sentence)
- Source mode cannot tell a table from an inline call, so the cells join the sentence: 'Cells follow: Alpha Beta and end.'
  - source exact text (content-values/table-in-sentence)
- Source order follows the argument list, so the attribution, which is written first, is emitted before the quote body. The quote is an inline value, so the output is 'Quoted author Quoted words'.
  - source exact text (boundaries/quote)
- Table cells are inline values in source mode, so all cells share one unit: 'Head A Head B Row one A ...'.
  - source exact text (compiled-gaps/table-repeat-header)
- The attribution is written first and the quote is an inline value, so the output is 'Before the quote. Author Quoted body text. After the quote.'
  - source exact text (content-values/quote-in-sentence)
- The definition's template text is its own unit as '(note: [...])', and the call is an inline value, so the output is '(note: [...])' then 'Texte X suite.'
  - source exact text (content-values/footnote-shadowed)
- Trailing content of a call is treated as inline, so the nested block joins the outer block text ('OuterBlock NestedBlock'). Source mode cannot tell a block call from an inline call.
  - source exact text (boundaries/nested-block)
